# invest_bot

Telegram-бот для портфеля:
- кнопки: отчёт, диаграммы, лидеры дня, позиции, выплаты, цели, уведомления;
- отчёты с диаграммами в 9:00 и 22:00 МСК по будням;
- уведомления о сильных движениях (порог 2/3/5%) и ценах-целях.

Работает целиком в GitHub Actions (`.github/workflows/serve.yml`): один запуск живёт ~5 ч 50 мин и слушает Telegram, новый стартует каждые 6 часов.

## Безопасность

- Портфель лежит только в зашифрованном виде (`portfolio.json.enc`, AES-256); ключ — секрет `PORTFOLIO_KEY`.
- Состояние (настройки, история капитала) хранится в кэше Actions, а не в репозитории.
- Бот отвечает только владельцу (`TG_CHAT_ID`), остальные сообщения игнорируются.
- Токен бота — только в секрете `TG_TOKEN`. В логи бот не пишет суммы и состав портфеля.
- Бот только читает котировки Мосбиржи и цены ЦБ: доступа к брокерскому счёту и сделкам у него нет.
