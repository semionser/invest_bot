# invest_bot

Telegram-бот для портфеля:
- кнопки: отчёт, дашборд, лидеры дня, позиции, выплаты, цели, уведомления;
- дашборд: капитал, результат с покупки по каждой бумаге, доли позиций, структура, движение за день, история капитала, купоны и дивиденды по месяцам (график купонов берётся с Мосбиржи);
- отчёты с диаграммами в 9:00 и 22:00 МСК по будням;
- уведомления о сильных движениях (порог 2/3/5%) и ценах-целях.

Работает целиком в GitHub Actions (`.github/workflows/serve.yml`): один запуск живёт ~5 ч 50 мин и слушает Telegram, следующий уже ждёт в очереди и стартует сразу после него.

## Безопасность

- Портфель лежит только в зашифрованном виде (`portfolio.json.enc`, AES-256); ключ — секрет `PORTFOLIO_KEY`.
- Состояние (настройки, история капитала) хранится в кэше Actions, а не в репозитории.
- Бот отвечает только владельцу (`TG_CHAT_ID`) и только в личном чате; группы и чужие сообщения игнорируются.
- Цены покупки тоже лежат только в зашифрованном файле.
- Токен бота — только в секрете `TG_TOKEN`. В логи (они публичные) бот пишет только тип ошибки: без сумм, состава портфеля и текста запросов; токен вырезается из любых сообщений об ошибках.
- Бот только читает котировки Мосбиржи и цены ЦБ: доступа к брокерскому счёту и сделкам у него нет.
